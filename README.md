# Nicolò Castellini — Personal website

A responsive personal biography and portfolio landing page built with Next.js,
vinext, and Framer Motion.

## Quick start

```bash
npm install
npm run dev
npm run build
```

## Features

- interactive motion and shape morphing
- responsive editorial layout
- accessible reduced-motion support
- Cloudflare-compatible production output

## Deployment

Pushes to `main` are built and deployed automatically to GitHub Pages at
<https://ex3meex.github.io/Nico/>.
